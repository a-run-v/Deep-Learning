## Deep Learning
Welcome to my deep learning repository, designed specifically with 
beginners in mind.

This directory contains fundamental concepts of **Deep Learning**, 
covering basic knowledge that will allow you jump-start your journey into 
this fascinating field. It is recommended for anyone who want a quick overview before diving deeper or exploring 
advanced topics related to Deep Learning models like Convolutional Neural 
Networks (CNN), Recurrent neural networks, Generative Adversarial Network( 
GAN) and Transformers.

Hope this brief introduction serves as a starting point on your 
exciting journey into Deep Learning!
